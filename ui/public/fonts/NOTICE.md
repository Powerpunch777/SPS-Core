# Bundled UI Fonts

SPS uses Pretendard Variable for Korean and Latin interface text. The font is
bundled locally so the interface does not depend on installed system fonts or a CDN.

## Pretendard

- Revision: 5c41199ea0024a9e0b2cb31735265056e5472d76

- Source: packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2

Inter remains bundled as a compatible Latin fallback for existing UI surfaces.

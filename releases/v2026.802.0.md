# SPS Core v2026.802.0

> Released: 2026-08-02

This release establishes the workflow-neutral SPS Core foundation for local-first, multi-computer agent workspaces.

## Highlights

- **Host and Workspace foundation** - Adds Host identity, membership bootstrap, SPS Node execution grants, Workspace Sources, and the neutral Workspace shell used by plugins.
- **Plugin lifecycle and diagnostics** - Makes plugin activation idempotent, adds rollback-safe development upgrades, exposes canonical diagnostics, and scopes plugin jobs to Workspaces.
- **Marketplace discovery assistant** - Adds read-only plugin discovery, a persistent Marketplace Assistant runtime, and safe MCP search tools without silently installing plugins.
- **Host workspace integration** - Completes the Host UI bridge, node grant visibility, Workspace Source controls, bounded runtime logs, and the integrated SPS Workspace shell.
- **Safe recovery** - Adds Host-only company and Workspace restore, permits restore only into an empty Host, and sanitizes credentials, leases, and transient runtime authority after import.

## Security And Reliability

- Aligns production dependency overrides and the pnpm 11 lockfile with the secure dependency baseline.
- Fixes migration lineage and marketplace cursor precision issues.
- Corrects SSH callback bridging while preserving SPS Node execution behavior.
- Expands OpenAPI coverage for Workspace, plugin lifecycle, Marketplace, and recovery routes.
- Stabilizes scheduler cleanup, heartbeat recovery, signoff checkout, and project route tests against real asynchronous runtime behavior.

## Upgrade Notes

- Apply the bundled database migrations before enabling the new Workspace and plugin lifecycle surfaces.
- Review SPS Node execution grants after upgrade. Restored data never inherits trusted runtime authority automatically.
- Plugins should declare their required SPS Core and SDK compatibility ranges before activation.
